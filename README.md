# AutoFishS

A fishing helper mod for Starcatcher.

## What it does

- **Minigame auto-hit**: Automatically completes the QTE event.
- **Auto-reel**: Reels in automatically when a fish bites.
- **Auto-cast**: Casts again automatically after each catch.
- **Fishing blacklist**: Don't want certain fish? Add them to the blacklist and the mod will skip them.

## Controls

- **F8**: open the settings screen.
- **F7**: open the fishing blacklist (click a fish to toggle it).

## Settings

- **Minigame auto-hit**: on/off
- **Auto-reel / Auto-cast**: on/off
- **Hit interval (seconds)**: minimum wait between auto hits
- **Mode**: `AUTO` = hit; `PERFECT` = aim for perfect
- **Treasure focus**: focus treasure spots when present
- **Click frozen/explosive spots**: off by default (they penalize progress / freeze the pointer)
- **Fishing blacklist**: toggle in the F7 screen; red slots = blacklisted

## Notes

- Does not activate during **tournaments**, nor does it apply to fish you haven't **unlocked** yet. May affect vanilla fishing rod behavior.
