# AutoFishS
一个用于捕星者的钓鱼辅助模组。

## 它能帮你做什么
- **小游戏自动命中**：自动完成QTE事件。
- **自动收竿**：鱼上钩（咬钩）时自动右键收竿。
- **自动抛竿**：钓完一条自动再抛。
- **钓鱼黑名单**：有些鱼不想钓？把鱼加进黑名单，钓到它就直接放弃。

## 按键
- **F8**：打开设置界面
- **F7**：打开钓鱼黑名单（点一下鱼就切换"拉黑/不拉黑"）

## 设置
- **小游戏自动命中**：开/关自动打小游戏
- **自动收竿 / 自动抛竿**：开/关
- **命中间隔（秒）**：两次自动命中之间最少等待的时间
- **模式**：`AUTO`＝命中；`PERFECT`＝追求完美
- **宝藏专注**：有宝藏钓点时，先钓宝藏
- **点击冰冻/爆炸钓点**：默认不打（会扣进度/冻指针）
- **钓鱼黑名单**：在 F7 界面点鱼切换，红格子＝已拉黑

## 注意事项
- 不会在**锦标赛**中启用；也不会对**未解锁的鱼**生效。有可能影响原版钓竿的行为。
